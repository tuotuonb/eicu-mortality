# 数据质控报告

分析数据集共 1668 例，建模组 1217 例，验证组 451 例。

## 1. 缺失率较高的变量（> 40%）

这些变量不适合直接进入预测模型，只作为描述或敏感性分析使用：

| 变量 | 中文名 | 缺失率 |
|---|---|---|
| `albumin` | 白蛋白 | 61.0% |
| `bilirubin` | 总胆红素 | 64.7% |
| `urine_24h` | 首日尿量 | 50.9% |
| `ph` | 动脉血 pH | 81.5% |
| `pao2` | PaO2 | 81.5% |
| `fio2` | FiO2 | 81.5% |
| `lactate_max` | 乳酸（最高值） | 68.5% |
| `lactate_first` | 乳酸（首次值） | 68.5% |
| `inr_max` | INR（最高值） | 51.9% |

## 2. 一致性校验：两个来源的肌酐是否吻合

APACHE 表记录的是首日「最差」肌酐；本项目又从原始检验表（相当于 LIS）用 SQL 独立提取了首日最高肌酐。
两者一致，说明 SQL 的时间窗口和清洗规则是正确的。

| 指标 | 结果 |
|---|---|
| 配对例数 | 1267 |
| Spearman 相关系数 | 0.947 |
| 差值 ≤ 0.1 mg/dL 的比例(%) | 69.8 |
| 差值中位数(mg/dL) | 0.0 |

## 3. 自己从原始检验表提取，缺失率明显更低

APACHE 表只记录用于评分的那一个值，很多患者没有记录；原始检验表保留了全部检验结果。
按入 ICU 前 6 小时至入 ICU 后 24 小时的时间窗口重新提取后，缺失率大幅下降，建模时优先使用 SQL 提取的版本：

| 指标 | APACHE 表缺失率 | SQL 提取缺失率 |
|---|---|---|
| 尿素氮 | 24.1% | 5.5% |
| 肌酐 | 23.8% | 5.6% |
| 白细胞 | 29.2% | 7.6% |
| 红细胞压积 / 血红蛋白 | 26.9% | 7.8% |
